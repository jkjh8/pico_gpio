GPIO Control - All Channels

Command Description
getins,id Get all 16 inputs (CHANNEL: in,id,binary / BYTES: ins,id,low,high)
getouts,id Get all 16 outputs (CHANNEL: out,id,binary / BYTES: outs,id,low,high)
sets,id,binary Set all 16 outputs with binary (id:0=all, e.g., sets,1,1010101010101010)
setb,id,low,high Set all 16 outputs with 2 bytes (id:0=all, e.g., setb,1,255,128)

GPIO Control - Single Channel

Command Description
set,id,ch,val Set single output (id:0=all/1-254, ch:1-16, val:0/1)
getin,id,ch Get single input (returns: true/false)
getout,id,ch Get single output (returns: true/false)
